首次安装使用指引

Step 1 下载安装文件

在当前页面下载最新版 Revocoder、VB-Cable Installer 以及 WinUHid Manager。

Revocoder：主程序与主界面。

VB-Cable Installer：在设备上构建虚拟声卡与声道。

WinUHid Manager：在设备上构建虚拟输入设备。

以上软件都需要通过右键“以管理员身份运行”，任一执行文件如果弹出“Windows 已保护你的电脑”窗口，则需要点击该窗口中的“更多信息”再点击“仍要运行”，即可正常打开。

*注意：因本软件未经历 Microsoft 认证流程，弹出保护窗口属于正常情况。

Step 2 安装 VB-Cable

仅首次安装需要。在解压后的文件夹内，右键 VBCABLE_Setup_x64 安装程序，选择以管理员身份运行，并在弹出的权限窗口中选择允许。

在 VB-Cable 界面中选择 Install Driver 即安装驱动，等待弹窗提示安装成功后手动进行一次系统重启（重启是必要的）。

打开声音设置面板，确保将输入设备切换到 CABLE Output，但不要将 CABLE Input 设置为默认输出。

Step 3 安装 WinUHid

仅首次安装需要。右键 WinUHid Manager 安装程序，选择以管理员身份运行，并在弹出的权限窗口中选择允许。

在 WinUHid Manager 界面中选择 Clean and Reinstall 即安装驱动，等待完全安装成功后手动进行一次系统重启（重启是必要的）。

重启后再次右键 WinUHid Manager 安装程序，选择以管理员身份运行，并在弹出的权限窗口中选择允许。在 WinUHid Manager 界面查看 Device、Driver、Packages 的状态都为正确时 WinUHid 的安装结束，反之若有任意状态有问题，则需重新安装，安装后重启并重新查看 Device、Driver、Packages 的状态。

Step 4 连接遥控器

进入 Windows 蓝牙设置页面，选择添加设备，同时也需要将你当前手中需要连接的设备触发连接状态。

选择列表中你的设备，进行连接，连接完成后，你的设备会在蓝牙列表出现并显示设备名称、设备电量以及"已连接"字样。

Step 5 使用 Revocoder

当你能确保前面的安装完整完成，便可右键 Revocoder 程序，选择以管理员身份运行，并在弹出的权限窗口中选择允许。

等待一会儿，Revocoder 会自动连接你的设备、自动初始化。你可以点击左下角的状态，查看细致的状态信息。

Q&A

如何卸载

同样以管理员身份运行 VB-Cable Installer 选择 Remove Driver 然后重启，再以管理员身份运行进入 WinUHid Manager 选择 Uninstall Driver 然后重启，即可将所有需要的驱动移除。

为什么 发送输入 SendInput 以及 按键抑制 RawInput 有时候呈现黄色状态（初始化状态）

发送输入 SendInput 以及 按键抑制 RawInput 这两个状态的判定依赖于你的设备发送真实的按键或行为信息，才能正确确定真实状态。在功能无误的情况下，一般会在真实使用一小段时间后自动确认完成状态。
