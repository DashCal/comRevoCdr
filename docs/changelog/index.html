更新日志

查看 Revocoder 的版本更新记录与新功能

v1.0.6

新增

  • 语音倒计时浮窗：支持独立透明窗口显示 60 秒倒计时，可拖动定位并持久化位置，圆环进度与数字同步变化
  • 状态栏倒计时药丸：状态栏几何中心以药丸形 SVG 进度条呈现倒计时，支持深色与浅色模式自适应

修复

  • 修复首次启动时默认按键映射无法触发的问题，根因为新旧格式解析器的兼容性缺陷
  • 修复确定键（OK）在抑制 Enter 关闭状态下仍显示自定义映射而非 Enter 的显示一致性问题
  • 修复信息存储系统在断电场景下的数据完整性风险，补充原子写入的磁盘同步保障
  • 修复配置文件损坏时应用无法启动的问题，增加优雅降级与自动备份机制
  • 修复前端保存设备配置时后端独有字段被静默重置的问题，改为增量合并策略

改进

  • 信息存储体系全面加固：原子写入、损坏降级、字段保护、时间戳备份、日志追踪
  • 确定键与抑制 Enter 开关实现前后端联动，关闭状态下强制 Enter 映射并禁用自定义编辑
  • 手动输入与更多选项中的未完成功能标记为禁用状态，避免用户误操作
  • 设置面板音频区域行间距优化，全局设置页面标识与版本信息层级清晰化
  • 构建流程重构：独立页面单独编译，避免多入口构建的注入异常

v1.0.5

新增

  • 七状态系统架构设计：将运行状态划分为语音组与按键组两套独立体系，各自拥有精确的错误枚举与优雅降级策略
  • VB-CABLE 七状态精确检测：从简单的就绪判断扩展为 Ready、NotInstalled、PartiallyInstalled、NeedsReboot、NotDefaultMic、EndpointError、ProbeFailed 七种状态
  • 设备级按键抑制宽限期机制：通过 suppress_active 标记结合 50ms 宽限期，实现遥控器与物理键盘共用 VK 码时的精确区分
  • WinUHid Manager GUI 工具：基于 Python + tkinter 的驱动管理工具，支持智能检测、清理重复实例、一键安装
  • WinUHid 预签名分发方案：自签名证书 + Inf2Cat + SignTool 流水线，实现免禁用签名验证的一键安装

修复

  • 修复 VB-CABLE ready 缓存永不过期的问题，引入 30 秒 TTL 机制支持运行时安装与卸载检测
  • 修复 Menu 键与 TV 键长按后原生功能穿透的问题，通过 suppress_active 宽限期机制在不误伤物理键盘的前提下完整覆盖
  • 修复 tap_vks 混合使用 WinUHid 与 SendInput 导致普通按键在 WinUHid 异常时无法注入的问题，统一为纯 SendInput + EXTRA_INFO

改进

  • 按键系统架构修正：普通按键统一走 SendInput 注入路径，WinUHid 仅服务于语音键的 IME 快捷键注入，两条路径完全独立
  • 按键抑制决策链审查：识别并记录 10 层决策链中的三处逻辑冗余，为后续简化重构提供依据
  • LL 钩子全键追踪日志：所有非注入键事件均记录 VK 码与抑制决策路径，便于运行时问题排查

v1.0.4

新增

  • 事件驱动状态架构：状态轮询从 120 次/分钟 IPC 优化为后端 status-watcher 线程事件驱动 + 30 秒兜底轮询 + 窗口感知
  • 深浅色主题系统：双主题体系，支持手动切换与系统主题自动跟随

修复

  • 修复蓝牙键盘被误判为遥控器导致空格与回车失效的问题，改用精确 VID/PID 匹配替代宽泛关键词
  • 修复 OK 键单击触发双动作的时序竞争，在 input_session 中提前标记信号并结合 BLE 通知时间戳窗口判断
  • 修复物理键盘 Enter 被误吞的问题，移除 tap_ready 全局标志，改为仅依赖 recent_signal 判断

改进

  • 按键抑制状态追踪：从 Raw Input 设备发现改为三态状态机（待命/已激活/异常），支持自动恢复
  • VB-CABLE 音频路由排查：定位微信语音只收 1 秒的根因为 CABLE Input 作为默认播放设备时系统音频混入

v1.0.3

新增

  • Raw Input 设备级按键抑制：基于 hDevice 设备句柄实现遥控器与物理键盘的精确区分，在 LL 钩子层面按设备来源决定是否拦截
  • Enter 键强制抑制开关：用户可控的全局开关，开启后无条件拦截所有 Enter 事件（含物理键盘），作为信号窗口机制的兜底方案
  • 按键抑制链路状态追踪：三态状态机（待命/已激活/异常）监控 HID Tap 与 GATT 双路径的抑制链路健康状态

修复

  • 修复 WinUHid 启动预加载状态延迟导致虚拟键盘状态显示为待命的问题，通过后台线程预加载消除启动时的虚假异常
  • 修复 TV 键 Shift+Enter 不触发的问题

改进

  • 梳理从信号接收到事件到达应用的六阶段完整生命周期，明确注入系统与抑制系统的职责边界
  • 抑制决策链从松散的条件判断整理为结构化的 6 层决策链，每层职责清晰、数据来源可追溯

v1.0.2

新增

  • 遥控器按键映射多模式支持：单击、双击、长按三种触发模式，支持 SingleKey、ComboKey、TextInput、LaunchApp 四种动作类型
  • 按键映射 UI 编辑器：可视化按键绑定配置，支持键盘实时录入与媒体键选取

修复

  • 修复按键映射中的时序竞争问题，确保信号标记在固件 VK 事件到达之前完成
  • 修复原生键穿透的完整链路问题，涵盖信号窗口过期、配置检查误伤物理键盘等边界场景

改进

  • 简化应用启动流程

v1.0.1

新增

  • 小米遥控器 2 Pro BLE 桥接核心功能：设备扫描、连接、按键事件接收、音频流订阅
  • 按键注入双通道架构：SendInput 软件级注入与 WinUHid 硬件级注入并行，支持按场景自动选择
  • WinUHid 虚拟 HID 驱动适配：从 UMDF 2.33 降级至 2.31 以兼容 Windows 10，完成编译、签名、安装的完整流程
  • VB-CABLE 虚拟声卡集成：音频路由通道建立，支持遥控器麦克风音频经虚拟声卡输入至系统输入法
