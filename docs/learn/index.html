使用文档

学习如何使用 Revocoder 的各项功能

快速开始

安装完成后，按照以下步骤开始使用 Revocoder：

  1. 确保蓝牙遥控器已配对并连接到 Windows 设备
  2. 以管理员身份运行 Revocoder
  3. 等待程序自动连接设备并初始化
  4. 点击左下角的状态指示器，查看连接状态

语音输入

Revocoder 将遥控器的语音键映射为系统语音输入快捷键。

使用方法

  • 按住遥控器上的语音键开始说话
  • 松开按键，语音将自动转换为文字输入到当前焦点位置
  • 支持大多数输入法和文本编辑器

注意事项

  • 确保 VB-Cable 已正确安装并设置为默认输入设备
  • 首次使用可能需要等待几秒钟进行设备识别

快捷键自定义

Revocoder 支持将遥控器按键映射为自定义快捷键。

支持的按键映射

  • 单击：触发一次快捷键
  • 双击：触发另一次快捷键
  • 长按：触发第三次快捷键

每个按键最多支持三种不同的快捷键映射，让你的遥控器变得更加灵活。

媒体控制

Revocoder 可以控制系统媒体播放。

  • 播放/暂停：按下播放键
  • 上一首/下一首：使用左右方向键
  • 音量调节：使用加减键

演示模式

Revocoder 可以作为演示遥控器使用。

  • 下一张：按下右方向键
  • 上一张：按下左方向键
  • 开始/结束演示：按下确认键

配合 PowerPoint、Keynote 等演示软件使用效果更佳。

故障排除

设备无法连接

  • 检查蓝牙是否已开启
  • 确认遥控器已进入配对模式
  • 尝试重启 Revocoder

语音输入无响应

  • 检查 VB-Cable 是否已安装
  • 确认系统声音设置中输入设备已切换到 CABLE Output
  • 重启 Revocoder 并等待初始化完成

快捷键不生效

  • 确认 WinUHid 驱动已正确安装
  • 以管理员身份运行 Revocoder
  • 检查快捷键配置是否正确
